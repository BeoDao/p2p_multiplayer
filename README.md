# KAG2 Web — King Arthur's Gold 스타일 웹 게임

브라우저에서 돌아가는 2D 팀 대전 게임. 파괴/건설 가능한 타일 지형, 기사·궁수·건축가 3직업, 깃발 뺏기(CTF).
**호스트 없는 P2P 결정론적 락스텝** 으로 동기화되며, **2D 스켈레탈 애니메이션**(본 리깅) 으로 캐릭터를 그린다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 정적 파일 (아무 정적 호스팅에 올리면 됨)
npm test           # 결정론/넷코드/게임 규칙 테스트
```

메뉴에서 **방 코드** 를 정하고 "온라인 참가 / 생성" 을 누르면 같은 코드를 입력한 사람끼리 자동으로 연결된다.
URL 의 `#코드` 를 공유하면 된다. 시그널링은 공개 Nostr 릴레이(Trystero)를 쓰므로 별도 서버가 필요 없다.
(`?strategy=torrent` 로 WebTorrent 트래커, `?relays=wss://...` 로 자체 릴레이 지정 가능)

조작: `A/D` 이동, `W/Space` 점프, 사다리 `W/S`, 좌클릭 공격/파괴/설치, 우클릭(또는 Shift) 방패, `1~9`/휠 아이템, 기지 안에서 `F1~F3` 직업 변경(제자리, 죽은 동안도 가능), 작업장 위에서 `E` 구매(기사 폭탄·궁수 화살, 금 소모) 및 자동 회복, `Tab` 점수판.

  render/      PixiJS 렌더링 (부동소수점 자유)
    skeleton.ts      본 트리 + 클립 재생 + 파츠 부착 (2D 스켈레탈)
    partsFactory.ts  기본 프로시저럴 파츠/타일 그림

  main.ts      메뉴, 입력, 게임 루프

## 결정론 (동기화) 규칙

- 시뮬(`src/sim`)은 **정수만** 사용한다. 위치/속도는 고정소수점(1px = 256 단위), 각도는 이진각(4096 = 360°),
  삼각함수는 정수 CORDIC 테이블, 제곱근은 정수 뉴턴법. `Math.sin/sqrt/random`, `Date` 금지.
- 모든 피어가 같은 시드로 같은 맵을 만들고, 매 틱(30Hz) **입력만** 교환한다. 틱 t 는 그 틱의 활성 멤버 전원의
  입력이 도착해야 진행된다 (락스텝, 입력 지연 2틱 ≈ 67ms).
- 플레이어 배열은 id 순으로 정렬 유지, 반복 순서가 항상 같다. 60틱마다 상태 해시를 교환해 디싱크를 검출한다.

## 호스트 없는 P2P

- WebRTC 풀메시: 모든 피어가 서로 직접 연결된다. 누가 나가도 다른 연결은 그대로다.
- "코디네이터" = 현재 활성 멤버 중 가장 작은 pid. 참가/이탈 시점을 공표하고 늦게 온 피어에게 스냅샷을 준다.
  상태는 전원이 갖고 있으므로 코디네이터가 나가면 다음 pid 가 **즉시** 이어받는다 (방장 없음).
- 이탈 처리: 코디네이터가 남은 피어들에게 이탈자의 마지막 입력을 질의(`leaveq/leaver`)해 가장 늦은 틱을 채택,
  그 뒤는 빈 입력으로 채운 뒤 이탈 틱을 공표(`leave`). 이미 다르게 진행한 피어는 스냅샷으로 재동기화한다.
- 참가: `joinreq` → 코디네이터가 pid·참가 틱 J 공표(`join`) → 틱 J 도달 시 스냅샷 전송 → 참가자는 J 부터 입력 재생.
- 창립 경합(동시에 두 명이 방을 만듦): 세션 id 가 큰 쪽이 자동으로 양보하고 재참가한다.
- 4초 이상 입력이 오지 않는 멤버는 연결된 멤버 중 최소 pid 가 이탈 처리한다. 정상 종료 시 `bye` 로 즉시 통지.

## 아이템/스킨 교체 방법

1. **텍스처 PNG 교체 (코드 수정 없음)**: `public/assets/parts/manifest.json` 에 `{ "keys": ["head_knight", "weapon_sword"] }`
   처럼 키를 적고 같은 폴더에 `head_knight.png` 등을 두면 기본 프로시저럴 그림 대신 사용된다.
   타일은 `public/assets/tiles/manifest.json` + `dirt.png`(8×8, 가로로 변형을 이어붙여도 됨).
2. **새 무기**: `items.json` 에 `{ id, kind:"weapon", part:"weapon_xxx", icon, rot, ox, oy }` 추가 → `classes.json` 핫바에 id 추가
   → 파츠 그림은 `partsFactory.ts` 의 `PART_PAINTERS` 또는 PNG 로. 동작 로직은 `world.ts` `updateActions` 의 `switch (item.id)`.
3. **새 블록**: `tiles.json` 에 타일 추가 + `items.json` 에 `{ kind:"block", tile, cost }` 추가. 끝.
4. **새 스킨**: `skins.json` 에 `"myskin": { "extends": "base", "vars": { "$head": "head_my", "$back": "none" } }`
   추가하고 `classes.json` 의 `skin` 을 바꾼다. 파츠 구성 자체를 바꾸려면 `parts` 배열을 다시 정의(본·앵커·z).
5. **새 애니메이션**: `animations.json` 에 클립 추가. `overlay: true` 클립은 팔 등 일부 본만 덮어쓴다.
   렌더러 `updatePlayer` 에서 상태 → 클립 선택.

## 개발용 치트 (기본 비활성)

키 하나로 발동하는 치트는 없다. `` ` `` 키를 누르면 명령 프롬프트가 열리고 `/cheat` 로 목록을 볼 수 있다:
`/res`(자원 +1000), `/dig`(타일 즉사 토글), `/heal`. 명령은 입력에 실려 전송되므로 P2P 에서도 동기화된다.
**릴리즈 시**: `src/main.ts` 의 `import { runCheat } from './dev/cheats'` 줄과 `runCheat(...)` 호출 줄을 주석 처리하고,
`src/sim/world.ts` 의 `CHEATS_ENABLED` 를 `false` 로 바꾼다 (둘 중 하나만 해도 막힌다).

## UI 언어

기본 영어(`<html lang="en">`). 지원 언어: 영어·일본어·러시아어·중국어·아랍어 — 메뉴 상단 버튼 또는 게임 중 `Esc` 설정의 언어 버튼으로 즉시 전환(재접속 없음), `?lang=ja` 로 강제, 선택은 localStorage 에 저장되고 첫 방문은 브라우저 언어를 따른다.
**한국어 자체 번역은 제공하지 않는다**(게임물관리위원회 등급 심사 대상이 되므로) — 한국어 사용자는 Chrome 자동 번역에 맡긴다.
문자열은 `src/render/i18n.ts` 의 `STRINGS`, 직업/아이템 이름은 JSON 의 `label`(영어) + `labels.{ja,ru,zh,ar}`. 새 언어 추가 = `LANGS`/`STRINGS` 에 항목 추가.
영어 UI 는 Chrome 자동 번역과 호환되도록 이름·숫자·키 표시에 `translate="no"` 를 붙였다. 아랍어는 텍스트 방향만 RTL(`--dir`).

## 게임 규칙 요약

- **뒷벽**: 흙/돌/금을 파면 흙 뒷벽이 남는다. 앞 타일은 "그 칸 또는 인접 칸에 뒷벽" 또는 "인접 타일"이 있어야 설치되고, 뒷벽(자기 칸/인접 칸)이 붕괴 판정의 고정점이다. 앞이 빈 칸을 새로 클릭하면 뒷벽을 판다(앞 타일을 파던 홀드로는 뒷벽이 안 파짐).
- **타일 물리**: 타일이 사라질 때 이웃 덩어리를 BFS 로 검사, 고정점(bedrock/뒷벽 있는 칸)에 닿지 않으면 끊긴 지점에서 가까운 순으로 2틱 간격 순차 붕괴. 나무(트렁크·잎)는 별도 그룹: 나무끼리만 연결되고 밑동 아래 고체에만 의존하며, 다른 타일의 지지대가 되지 않는다.
- **시선**: 공격/채굴/건설은 플레이어 중심에서 목표까지 고체 타일이 없어야 한다(자기 팀 문은 통과). 폭탄 피해도 시선 필요(문 포함 차단).
- **작업장**: 건축가가 설치(나무 50 + 돌 20). 위에 서면 30틱마다 ♥¼ 회복, `E` 로 직업별 소모품 구매(`classes.json` 의 `shop`).
- **효과음**: WebAudio 합성. `public/assets/sfx/manifest.json` + `<kind>.wav` 로 교체.
- **물**: 칸마다 수위 0~8 (정수). 2틱마다 아래로 흐르고 좌우로 평준화되는 셀룰러 오토마타, 총량 보존. 중앙 호수. 몸이 절반 이상 잠기면 수영(느린 낙하, Space 로 상승), 머리가 잠기면 10초 후 익사 피해.
- **맵**: 왼쪽 절반을 생성해 오른쪽에 거울 복사(좌우 대칭). 기지 평지 + 초기 작업장, 중앙에 금 집중, 나무는 캐노피가 완전히 비어 있는 자리에만.
- **아이템 드롭/획득**: 바닥 아이템(`Drop`: 나무·돌·금·폭탄·화살)은 중력/타일 충돌을 받고 60초 뒤 사라지며, 살아있는 플레이어가 겹치면 줍는다(+N 표시). 나무 기둥은 파괴/쓰러질 때 자원을 바로 주지 않고 **통나무 아이템**을 떨어뜨린다(`tiles.json` 의 `drop: true`, 잎은 아무것도 안 줌). 사망 시 들고 있던 자원과 폭탄/화살이 떨어진다. 폭탄은 기사만·화살은 궁수만 최대치까지 줍고, 같은 종류가 가까이 멈춰 있으면 하나로 합쳐진다(상한 256개).
- **연출**: 고체 타일의 노출된 면에 1px 어두운 테두리(청크 경계는 이웃 청크도 갱신), 폭발·사망 시 거리 감쇠 화면 흔들림(`renderer.addShake`).
- **HUD**: 미니맵(우하단), `Enter` 채팅(전송 계층 메시지, 시뮬 무관), `Esc` 설정(볼륨/배율, localStorage), 설치 미리보기, 데미지 숫자.

## 수치 단위

- 길이: FP (1px = 256). 타일 = 8px = 2048.
- 체력: 1/4 하트 (4 = ♥1). 검 4, 화살 1~4(당김), 폭탄 최대 10.
- 시간: 틱 (30Hz).
